# Política de seguridad

DatosDemoCL genera archivos locales con datos de demostración y no consulta
servicios externos. Los RUT generados pueden coincidir con identificadores
reales; no uses la herramienta para generar documentos legales ni como método
de anonimización.

## Reportar una vulnerabilidad

No publiques detalles explotables en un issue público. Si GitHub Private
Vulnerability Reporting está habilitado para este repositorio, envía el
reporte por esa vía. Si no está disponible, contacta al mantenedor mediante el
perfil de GitHub del repositorio y comparte los detalles de forma privada.

Incluye la versión afectada, el sistema operativo, los pasos para reproducir,
el impacto observado y una posible mitigación. No adjuntes datos personales ni
archivos de clientes.

## Alcance

La revisión de seguridad cubre el código fuente de DatosDemoCL. No certifica
que los RUT sean inexistentes ni que los datos ficticios puedan reemplazar
datos personales en sistemas regulados.
